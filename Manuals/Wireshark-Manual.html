Wireshark Lab Setup – Beginner’s Manual

📖 Introduction

Wireshark is an open-source network protocol analyzer widely used in SOCs and incident response. It acts as the SOC’s microscope, allowing analysts to capture and inspect raw packet traffic to detect attacker techniques.

  • Capture and analyze live network traffic
  • Apply filters to isolate suspicious activity
  • Decode protocols like TCP, DNS, HTTP, and ICMP
  • Document findings with screenshots for recruiter‑ready proof

🎯 Why This Lab Matters

  • Shows ability to analyze raw network traffic — a core SOC skill
  • Provides visibility into attacker techniques like port scans, beaconing, and exfiltration
  • Builds proof of detection workflows with filters, screenshots, and playbooks

⚙️ Step‑by‑Step Setup

Step 1: Install Wireshark

Download from official site and install on your VM or host machine.

Step 2: Configure Capture Filters

tcp port 80

Step 3: Apply Display Filters

http.request

Step 4: Use Protocol Decoders

Inspect packet details in the middle pane to understand anomalies.

Step 5: Document Findings

Save annotated screenshots in screenshots/ folder with clear labels.

🚨 Incident Response Playbooks

IncidentDetection FilterResponsePurpose
Port Scan
tcp.flags.syn==1 && tcp.flags.ack==0
Identify source IP, block attackerDetects SYN scan behavior.
Suspicious DNS Beaconing
dns && ip.dst==<suspicious_IP>
Investigate domain, enrich with threat intelDetects repeated DNS queries.
HTTP Data Exfiltration
http && ip.src==<internal_IP>
Terminate connection, investigate hostDetects large outbound HTTP traffic.
ICMP Tunneling
icmp && data.len>100
Block ICMP traffic, alert SOCDetects covert channels.
Unencrypted Credentials
http.request.method==POST && tcp.port==80
Alert SOC, enforce HTTPSDetects sensitive data sent in cleartext.
